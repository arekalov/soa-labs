## Задание

Разработать спецификацию в формате OpenAPI для набора веб-сервисов
(текст задания — в [task.jpg](task.jpg)):

1. **Первый веб-сервис** управляет коллекцией объектов `SpaceMarine`
   (базовый CRUD + фильтрация, сортировка, пагинация + дополнительные операции).
2. **Второй веб-сервис** располагается на URL `/starship` и реализует дополнительные
   операции, связанные с вызовом API первого сервиса.

Для спецификации сгенерирована интерактивная веб-документация с помощью Swagger UI
с текстовым описанием функциональности каждой операции. Документация развёрнута
на сервере helios.

## API первого сервиса — SpaceMarine Service

Base path: `/api/v1`. Данные объектов передаются в формате JSON,
параметры операций — в URL запроса.

| Метод  | Путь                              | Описание |
|--------|-----------------------------------|----------|
| GET    | `/space-marines`                  | Массив элементов: фильтрация по любой комбинации полей (отдельный query-параметр на каждое поле), сортировка (`sort`, повторяемый, префикс `-` — по убыванию), пагинация (`page`, `size`) |
| POST   | `/space-marines`                  | Добавить новый элемент (`id` и `creationDate` генерируются сервером) |
| GET    | `/space-marines/{id}`             | Получить элемент по ИД |
| PUT    | `/space-marines/{id}`             | Обновить элемент |
| DELETE | `/space-marines/{id}`             | Удалить элемент |
| GET    | `/space-marines/health/min`       | Один (любой) объект с минимальным значением `health` |
| GET    | `/space-marines/groups/by-id`     | Группировка по `id` с количеством элементов в каждой группе |
| GET    | `/space-marines/count/by-chapter` | Количество объектов с заданным значением `chapter` (`?name=...&parentLegion=...`) |

Коды ошибок: `400` — некорректные параметры запроса, `404` — элемент не найден,
`422` — нарушение ограничений целостности класса (пустое `name`, `health ≤ 0`,
`coordinates.y > 12` и т.п.), `500` — внутренняя ошибка.

## API второго сервиса — Starship Service

Располагается на URL `/starship`, вызывает API первого сервиса.

| Метод | Путь                                              | Описание |
|-------|---------------------------------------------------|----------|
| POST  | `/starship/create/{id}/{name}`                    | Создать новый десантный корабль и сохранить его в БД |
| POST  | `/starship/{starship-id}/unload/{space-marine-id}`| Высадить выбранного десантника с корабля |

Дополнительно: `409` — корабль с таким `id` уже существует,
`503` — первый сервис недоступен.

## Как посмотреть документацию локально

```bash
python3 -m http.server 8000 -d docs
```

и открыть http://localhost:8000. Переключение между спецификациями сервисов —
через выпадающий список «Select a definition» в правом верхнем углу.
